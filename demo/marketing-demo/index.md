## Why Choose Tinyss?

- **Zero Configuration** — Point it at your markdown files and go. No config files, no setup wizards, no boilerplate.
- **Lightning Fast** — Pre-rendered HTML means your site loads instantly. No JavaScript frameworks, no hydration delays.
- **Developer Friendly** — Built on Node.js with Preact templates. Extend with plugins or create custom templates.
- **Deploy Anywhere** — Plain HTML output works on Netlify, Vercel, GitHub Pages, S3, or any web server.

## How It Works

Write your content in markdown. Run one command. Get a production-ready website.

```shell
npm init tinyss docs/**/* -o public
```

## Built-In Templates

Choose from professional templates designed for common use cases:

- **Documentation** — Clean sidebar navigation with table of contents. Perfect for technical docs and guides.
- **Blog** — Beautiful typography with post listings, dates, and reading time estimates.
- **Marketing** — Bold landing pages with hero sections, feature grids, and call-to-action buttons.
- **Portfolio** — Minimal project showcases with responsive image grids.
