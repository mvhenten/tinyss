## Why Static Sites?

Static sites offer several compelling advantages over dynamic alternatives:

- **Performance** — Pre-rendered HTML serves instantly, no server-side processing required
- **Security** — No database or server-side code means a dramatically reduced attack surface
- **Reliability** — Static files can be hosted anywhere, with near-perfect uptime
- **Cost** — Hosting static files is essentially free on most platforms

## Getting Started

Getting started with Tinyss is straightforward. Create your content in markdown, run a single command, and deploy the output anywhere.

```shell
npm init tinyss content/**/* -o public
```
